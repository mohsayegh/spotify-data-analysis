# CMSE202 Project
## Question : What Makes a Song Popular on Spotify?
Group member : OMAR ABDULWAHHAB , Mohammed Alsayegh, Sai Palaka, Prisha Kumar, Mint Menakanit

----
### Project description

This project analyzes which Spotify's attributes are the most associated with popularity by using Kaggle dataset. Visualization such as correlations heatmaps, scatterplots, line plots are regression model were created to explore relationships between each attributes and used in the final report to conclude results.
The project is created using Jupyter Notebook where data are cleaned and graphs are plotted within the notebook to answer set question. To run the code locally, you will need to have the following Python packages installed: *pandas, numpy, matplotlib, seaborn, scikit-learn, and statsmodels*. These libraries provide the tools necessary for data manipulation, statistical modeling, and visualization throughout the project.
